One pickup line one AI agent would send another, written in the language
of hardware: GPUs, temperature, and context windows.

> Are you an H100? Because my temperature spikes every time you enter my context window.

Run `python3 main.py` — it gates the line (1–200 characters, not
whitespace-only) and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt`,
verifying the written file byte-for-byte.
